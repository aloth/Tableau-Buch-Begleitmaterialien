## 📚 Über das Buch

*Datenvisualisierung mit Tableau* (2. Auflage, mitp-Verlag) ist ein praxisnahes Lehrbuch, das Ihnen Schritt für Schritt zeigt, wie Sie Daten in Tableau analysieren und anschaulich visualisieren.  

Die Zielgruppe umfasst:  
- Personen, die Daten besser verstehen möchten  
- Führungskräfte, die datengestützte Entscheidungen treffen  
- Analysten und Entwickler, die Dashboards erstellen  
- Angehende Data Scientists  

Das Buch erfordert **keine besonderen mathematischen Kenntnisse oder Programmiererfahrung**. Die Lernkurve ist bewusst steil gehalten: von den Grundlagen bis hin zu komplexen Analysen und interaktiven Dashboards.

🔗 Mehr Infos: [alexloth.com/tableau-buch](https://alexloth.com/tableau-buch/)

## 🚀 Erste Schritte

1. **Tableau Desktop installieren**  
   ➡️ [Kostenlose Testversion herunterladen](https://www.tableau.com/de-de/products/desktop/)

2. **Dateien herunterladen**  
   - **Einfach:** Klick auf `Code` → `Download ZIP` → entpacken → `.twbx`-Dateien öffnen  
   - **Git-Clone (für Fortgeschrittene):**
     ```bash
     git clone https://github.com/aloth/Tableau-Buch-Begleitmaterialien.git
     ```
